# Artist Images

Place artist photos in this directory. Images should be:

- Format: JPG or WebP
- Recommended size: 800x800px (square) or 1200x800px (landscape)
- File naming: Use kebab-case matching the image path in events.json

## Required Images

Based on events.json, you need:

- `ta-williams.jpg`
- `mondo-tiki-duo.jpg`
- `tom-llinas.jpg`
- `vintage-sound.jpg`
- `acoustic-live.jpg`
- `hunnitap.jpg`
- `rick-cupoli.jpg`
- `michele-wood.jpg`
- `jimmy-mazz.jpg`
- `a-trace-of-suspense.jpg`

Images will automatically hide if they fail to load, so you can add them gradually.
